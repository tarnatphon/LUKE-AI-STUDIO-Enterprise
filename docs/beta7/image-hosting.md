# ที่พักรูปสาธารณะ — ทำไม Instagram/LINE ต้องมี และจะเลิกพึ่ง imgbb ได้อย่างไร

อัปเดตข้อมูล: **ตุลาคม 2026** · ใช้ร่วมกับแท็บ **Connectors → ที่พักรูปสาธารณะ**
และ `docs/beta7/linkedin-posting.md`, `docs/beta7/free-high-da-publishing-platforms.md`

---

## 1. ทำไมต้องมีที่พักรูป (และทำไม Facebook/LinkedIn ไม่ต้อง)

| แพลตฟอร์ม | วิธีส่งรูป | ต้องมีที่พักรูปไหม |
| :--- | :--- | :--- |
| **Facebook** | `POST /{page}/photos` รับ**ไบต์ของไฟล์**ตรง ๆ (multipart) | **ไม่ต้อง** |
| **LinkedIn** | `initializeUpload` → `PUT` ไบต์ → ส่ง `content.media` / `multiImage` | **ไม่ต้อง** |
| **Instagram** | `POST /{ig-user-id}/media` รับ **`image_url`** แล้ว IG ไปดึงรูปเอง | **ต้อง** |
| **LINE (Messaging API)** | ข้อความแบบ `image` รับ **`originalContentUrl`** แล้ว LINE ไปดึงรูปเอง | **ต้อง** |

พูดให้ตรง: **ไม่มี API ไหนให้อัปโหลดไฟล์รูปเข้า Instagram หรือ LINE ได้โดยตรง**
เหตุผลคือทั้งสองดึงรูปจาก URL ที่เปิดสาธารณะได้ (IG มี resumable upload เฉพาะ **วิดีโอ/Reels**
ซึ่งเป็นเหตุผลที่ Reels ส่งไฟล์ตรงได้โดยไม่ต้องมีที่พักวิดีโอ)

เพราะฉะนั้น “เลิกพึ่ง imgbb” ทำได้ด้วยการ **เปลี่ยนที่พักรูป** ไม่ใช่ด้วยการ “อัปโหลดตรงไปแพลตฟอร์ม”
ซึ่งทำไม่ได้จริง ระบบจึงมีที่พักรูปให้เลือกหลายเจ้า แทนที่จะบังคับใช้ imgbb เจ้าเดียว

## 2. ลำดับที่ระบบลอง (โหมด `อัตโนมัติ`)

```
รูปที่มี publicUrl อยู่แล้ว  →  ใช้เลย (ไม่อัปโหลดซ้ำ)
        ↓ ไม่มี
เว็บของเราเอง (own)          →  ไม่ต้องพึ่งบุคคลที่สาม ไม่ต้องมี key
        ↓ ยังไม่ตั้งค่า / ล่ม
imgbb (ถ้ามี API key)
        ↓ ไม่มี key / ล้ม
catbox.moe                   →  ฟรี ไม่ต้องมี key (ถาวร)
        ↓ ล่ม
litterbox.catbox.moe         →  ฟรี ไม่ต้องมี key (ลบเองใน 72 ชม.)
        ↓ ล่มหมด
ไม่ส่ง + บอกทุกเจ้าที่ลองและสิ่งที่ต้องแก้
```

- ทุกเจ้าเป็น **ทางเลือก** ไม่มีเจ้าตัวบังคับ: ไม่มี key และไม่มีเว็บ ก็ยังโพสต์ได้
- ถ้าทุกเจ้าล้ม ระบบจะ **ไม่ส่งโพสต์** และบอกเหตุผล (ไม่ลดรูปคู่เหลือรูปเดียวเงียบ ๆ)
- เมื่อส่งจริง ผลการรันจะบันทึกว่าใช้ที่พักรูปเจ้าไหน (`imageHost`) เช่น `["publicUrl","catbox"]`

## 3. ตั้งค่าในแอป

**Social Agency → Connectors → “ที่พักรูปสาธารณะ (Instagram / LINE)”**

| ตัวเลือก | ใช้เมื่อไร |
| :--- | :--- |
| อัตโนมัติ | ค่าเริ่มต้น — ให้ระบบไล่ตามลำดับด้านบน |
| เว็บของเราเอง | มีเว็บไซต์และอยากเก็บรูปไว้ที่ตัวเอง (แนะนำสุด) |
| imgbb | มี API key อยู่แล้ว (ยังใช้ได้เหมือนเดิม) |
| catbox.moe | ไม่อยากสมัครอะไรเลย — ฟรี ไม่ต้องมี key |
| litterbox | เหมือน catbox แต่ลบรูปเองใน 72 ชม. (เหมาะกับโพสต์ที่ส่งทันที) |

กด **ทดสอบอัปโหลด** เพื่อยิงรูปสินค้าจริง 1 รูป (หรือไฟล์ทดสอบ 1×1 px ถ้ายังไม่มีรูปสินค้า)
ผ่านที่พักรูปที่เลือก แล้วดูว่าได้ URL กลับมาหรือไม่ — ค่าที่พิมพ์ในช่องยังไม่ถูกบันทึกจนกว่าจะกดบันทึก

## 4. สัญญาของ “เว็บของเราเอง”

ระบบยิง `POST` แบบ `multipart/form-data` ไปที่ URL ที่ตั้งไว้:

- ช่องไฟล์ชื่อ **`file`**
- ถ้าใส่ token ไว้ จะแนบ header `Authorization: Bearer <token>`
- ตอบกลับเป็น JSON `{"url": "https://…"}` (หรือข้อความเปล่า ๆ ที่เป็น URL ก็ได้)
- URL ที่ตอบกลับต้องขึ้นต้นด้วย `https://` และเปิดให้บุคคลทั่วไปโหลดได้ (IG/LINE จะไปดึง)

ตัวอย่าง PHP (วางไฟล์เดียวบนโฮสต์ของคุณ):

```php
<?php
// luke-upload.php — รับไฟล์จาก LUKE AI STUDIO แล้วคืน URL สาธารณะ
$TOKEN = "เปลี่ยนเป็นรหัสลับของคุณ";
if (($_SERVER['HTTP_AUTHORIZATION'] ?? '') !== "Bearer $TOKEN") {
  http_response_code(401); echo json_encode(["error" => "unauthorized"]); exit;
}
if (!isset($_FILES["file"]) || $_FILES["file"]["error"] !== UPLOAD_ERR_OK) {
  http_response_code(400); echo json_encode(["error" => "no file"]); exit;
}
$ext = strtolower(pathinfo($_FILES["file"]["name"], PATHINFO_EXTENSION));
if (!in_array($ext, ["jpg", "jpeg", "png", "webp"], true)) {
  http_response_code(415); echo json_encode(["error" => "unsupported type"]); exit;
}
$dir = __DIR__ . "/uploads";               // ต้องเปิดให้อ่านผ่าน https
if (!is_dir($dir)) mkdir($dir, 0755, true);
$name = bin2hex(random_bytes(8)) . "." . $ext;
if (!move_uploaded_file($_FILES["file"]["tmp_name"], "$dir/$name")) {
  http_response_code(500); echo json_encode(["error" => "cannot store"]); exit;
}
header("Content-Type: application/json");
echo json_encode(["url" => "https://" . $_SERVER["HTTP_HOST"] . "/uploads/" . $name]);
```

ข้อควรระวัง: โฟลเดอร์ `uploads` ต้องเสิร์ฟผ่าน https และควรจำกัดชนิดไฟล์/ขนาด
(ตัวอย่างตั้งเพดานโดย `upload_max_filesize` ของ PHP) — รูปที่ระบบส่งมามักไม่เกิน 2 MB

## 5. ความเป็นส่วนตัว (อ่านก่อนเลือกโฮสต์ฟรี)

- **เว็บของเราเอง** — รูปอยู่กับเรา ไม่มีบุคคลที่สาม
- **imgbb** — ต้องมีบัญชี/key รูปลบได้ด้วยตัวเอง เหมาะกับงานธุรกิจ
- **catbox / litterbox** — ไม่ต้องสมัครและไม่มีค่าใช้จ่าย แต่ **รูปจะอยู่บนเซิร์ฟเวอร์ของคนอื่น
  ที่ใครมีลิงก์ก็เปิดดูได้** และบริการเหล่านี้อาจล่ม/ลบไฟล์ได้โดยไม่แจ้ง (litterbox ลบเองใน 72 ชม.)
  เหมาะกับรูปโปรโมทที่เผยแพร่สาธารณะอยู่แล้ว ไม่เหมาะกับรูปสินค้าที่เป็นความลับหรือรูปที่ยังไม่ออกวางขาย

---

## 6. ข้อจำกัดที่ยังเหลือ

- รูปที่โพสต์แล้ว URL ของที่พักฟรีอาจหมดอายุภายหลัง — ไม่กระทบโพสต์ เพราะแพลตฟอร์มคัดลอกรูปไปเก็บเองตั้งแต่ตอนสร้างคอนเทนเนอร์
- ไม่มีการลบรูปออกจากที่พักฟรีอัตโนมัติ (catbox ไม่มี delete โดยไม่มีบัญชี) — ถ้าต้องลบ ให้ใช้เว็บของเราเองหรือ imgbb
- วิดีโอยังแยกทาง: Facebook/LINE ต้องการ URL วิดีโอสาธารณะ (ระบบยังใช้ `publicUrl` ที่มีอยู่), Reels ส่งไฟล์ตรงได้
